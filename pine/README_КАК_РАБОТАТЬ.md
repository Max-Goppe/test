# Как работать с REGME и VDO (настройка на GOLD, тюнинг по выгрузке MT5 M5 2022–2026)

## Файлы
- `pine/regme_dynamic_zones.pine` — индикатор зон ликвидности REGME (на графике).
- `pine/vdo_volume_direction.pine` — осциллятор направления объёма VDO (в отдельном окне).
- Оба файла актуальны в коммите `bfffd49`. Дубликаты для удобства копирования: `regme_dynamic_zones.txt` и `vdo_volume_direction.txt` в корне репозитория.

## Установка на TradingView
1. Откройте график XAUUSD, выберите таймфрейм (рекомендуется H1).
2. Внизу нажмите «Pine Editor» → вставьте содержимое файла целиком → «Сохранить» → «Добавить в график».
3. Проделайте то же со вторым файлом. REGME ляжет на цены, VDO — в нижнее окно.

## Переключатель таймфрейма
В каждом индикаторе есть группа **«Timeframe preset»** → параметр **Preset**:
- **Auto** (по умолчанию) — настройки подставляются автоматически под текущий ТФ графика.
- **M5 / M15 / H1** — можно принудительно выбрать пресет, не меняя ТФ графика.

Пресеты (результат тюнинга на ваших данных):
| Параметр | H1 | M15 | M5 |
|---|---|---|---|
| Объёмный импульс (множитель) | ×2.2 | ×1.8 | ×1.3 |
| Мин. тело свечи | ≥0.7 ATR | ≥0.5 ATR | ≥0.3 ATR |
| Мин. диапазон свечи | ≥1.1 ATR | ≥0.9 ATR | ≥0.7 ATR |
| REGME (VWMA+EMA) | 55/8 | 100/8 | 55/8 |
| Режим сигналов VDO | Band breakout + REGME | Band breakout + REGME | Band breakout only |

Любой параметр с подписью «(0 = from preset)» можно переопределить вручную: поставьте число — оно выиграет у пресета; 0 или пустая строка — снова берётся из пресета.

## REGME: как читать
- **Линия REGME**: зелёная — цена в бычьей зоне (выше средней), красная — в медвежьей.
- **Зоны**: рисуются только на объёмных импульсах (всплеск объёма + крупное тело). Зелёные — спрос (demand), красные — предложение (supply).
- **Первое касание зоны**: метка «T» и треугольник на баре. Бар создания зоны касанием не считается. Повторные касания не помечаются.
- Зона, которую коснулись, слегка затемняется; пробитая (close за её краем) сереет. Опция «Delete broken zones» — удалять пробитые.

### Сетап входа от зоны (основной)
1. Тренд по REGME: линия зелёная (покупки) или красная (продажи).
2. Рядом есть **нетронутая** зона противоположной стороны (цена идёт к ней).
3. Дождаться касания → сигнал «T».
4. Подтверждение: разворотная свеча (пин-бар/поглощение) ИЛИ сигнал VDO в ту же сторону.
5. Стоп: за дальний край зоны (или 1 ATR). Тейк: 1–2R либо следующая зона.
- Не торгуйте повторные касания одной зоны и касания против цвета REGME.

## VDO: как читать
- Осциллятор 0–100: выше 50 доминируют покупатели, ниже — продавцы. Белая линия — VDO, серая — его сигнальная EMA.
- **Динамические полосы** (красная/зелёная вокруг сигнальной) — нормальный диапазон шума.
- Режимы (параметр «Signal mode», по умолчанию из пресета):
  - **Band breakout + REGME** (рекомендуемый на H1/M15): вход, когда VDO пробивает полосу ПО НАПРАВЛЕНИЮ цены относительно REGME + объёмный всплеск. Единственный режим с положительным матожиданием на ваших данных (~+0.49 ATR на горизонте 24 баров на H1).
  - **Band breakout only**: то же без фильтра REGME (дефолт для M5).
  - **Reversal from zone (legacy)**: старая логика «отскок от 20/80» — на золоте убыточна, оставлена для сравнения.
- Маркировка: стрелки «A»/«V» на уровне линии — подтверждённые сигналы; маленькие треугольники у 20/80 — ранние (информационные, не торговые); подсветка фона — давление объёма.

## Алерты
Алерты создаются через будильник TradingView (⏰) → «Create alert» → ваш saved indicator:
- REGME: «Demand/Supply zone touched» (лучшее время — Once Per Bar / On bar close), «bullish/bearish dynamic zone» (создание новой зоны).
- VDO: «VDO buy» / «VDO sell».
Типовой сценарий: алерт на первое касание зоны REGME → открываете график и проверяете подтверждение по VDO.

## Чек-лист перед входом
- [ ] Пресет совпадает с рабочим ТФ (лучше H1, Preset = Auto).
- [ ] Цвет REGME = направление сделки.
- [ ] Зона нетронута (до касания «T»).
- [ ] Есть метка касания «T» на свежем баре.
- [ ] VDO дал сигнал в ту же сторону (breakout режима) или подтверждает свеча.
Любой пропущенный пункт — сделку пропускаем.

## Важное
- Тюнинг выполнен на XAUUSD (GOLD) M5 2022–2026. На других инструментах проверьте пресеты (Volume multiplier, Min body/ATR) — возможно, потребуется подстройка.
- Индикаторы — функциональная реконструкция по скриншотам, не приватная формула автора.
- Это не финансовая рекомендация; тестируйте стратегию на демо/бэктесте.
